# WorldWebMaster — Master Framework

WorldWebMaster is the reusable, brand-neutral web engine for:
- world geography
- countries and regions
- destinations and hubs
- events
- experiences
- marine/cruise layers
- media and video
- contributor submissions
- moderation/approval
- domain-ready experience routing

## Important
This package is NOT a website for any one brand.

It is infrastructure.

Independent brands such as Sunken Treasure Travels, The Orange Pair,
Secret & Hush, The Lobby, and The Original Blueprint Team LTD can use it
without becoming the same brand or business.

## Integration model

Brand website
    ↓
WorldWebMaster engine
    ↓
World / Places / Experiences / Media / Intelligence / Marine

The brand's existing website remains the source of truth for its own
content, identity, navigation and business logic.

WorldWebMaster is added as a reusable capability rather than replacing
the brand website.
