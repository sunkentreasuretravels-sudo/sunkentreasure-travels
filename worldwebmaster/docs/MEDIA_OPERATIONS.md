# Media Operations

## Adding an official destination image
1. Upload the licensed image through the media/admin system.
2. Associate it with the country or destination.
3. Record source, license and attribution.
4. Mark it approved.
5. Optionally mark it as hero/featured.
6. The site automatically resolves the new image.

No JavaScript or HTML path editing is required.

## Adding 40 customer photographs
1. Customer uses Share Your Journey.
2. Multiple files are uploaded in one submission.
3. Each asset is stored as a submission.
4. Automated screening flags potential issues.
5. Human reviewer approves or rejects.
6. Approved assets publish to the selected destination/event/experience gallery.

## Licensing
Only publish assets with documented rights/permission. Branded cruise-line imagery must be authorized or appropriately licensed.
