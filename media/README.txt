SUNKEN TREASURE TRAVELS® MEDIA ENVELOPE

Do not place customer media directly into the website code.

Workflow:
1. Customer submission enters media/inbox.
2. Processing/safety checks occur in media/processing.
3. Approved files move to media/approved.
4. Rejected files move to media/rejected.
5. Each approved asset receives metadata in the content/data layer and is attached to a geographic or experience ID.

This keeps media independent from the page itself. Adding 1 photo or 10,000 photos does not require rebuilding the website.
